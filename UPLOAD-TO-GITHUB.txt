ARANAV DIGITAL PORTFOLIO — V21.2 CORE CRAFT EDITION

1. Download and extract this ZIP on your computer.
2. Open the existing repository:
   https://github.com/ARANAVas/Aranav-Digital-Portfolio
3. Replace the repository's existing website files with the CONTENTS of this extracted folder.
   Keep the folder structure intact, especially the assets/ folder.
4. Confirm these files are at the repository root:
   - index.html
   - portfolio-core-v21.css
   - script-v21.js
   - theme-init-v21.js
   - privacy.html
   - 404.html
   - assets/
5. Commit the changes to the repository's configured GitHub Pages branch/root.
6. In GitHub, open Settings > Pages and confirm the existing source branch and folder are still correct.
7. After Pages publishes the commit, open the site and hard-refresh (Ctrl+F5 on desktop). On mobile, reload after the deployment has completed; clear cached site data only if the old styles still appear.

IMPORTANT
- This ZIP is source code; it does not publish the site automatically.
- Do not upload the ZIP as a single website file. Extract it and upload its contents.
- Do not delete the assets/ directory.
- Keep the file names as supplied. HTML uses the V21.2 cache-busting query strings for the current CSS and JavaScript.
- GitHub Pages does not apply the Vercel vercel.json or Netlify-style _headers file. GitHub Pages security headers must be checked against the host's supported settings.
- After publishing, use V21-DEVICE-CHECKLIST.md to check both themes and the Skills doors on real devices.
