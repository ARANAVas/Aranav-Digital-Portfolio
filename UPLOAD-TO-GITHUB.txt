UPDATE THE ARANAV PORTFOLIO ON GITHUB PAGES — V8 QA REFINED

1. Download and extract the V8 ZIP.
2. Open the Aranav-Digital-Portfolio GitHub repository.
3. Replace the existing index.html, styles.css, script.js and README.md.
4. Replace the complete assets folder too. Keep the folder structure unchanged.
5. Commit the changes to the main branch.
6. Open Settings > Pages and confirm: Deploy from a branch > main > /(root).
7. Open Actions and confirm the Pages deployment finishes successfully.
8. Check the published site:
   https://aranavsharma07.github.io/Aranav-Digital-Portfolio/

Do not upload only the HTML file. The CSS, JavaScript and complete assets folder are required.

THEMES

- Header toggle: premium white + crimson-red theme.
- The visitor's selected theme is remembered by the browser when storage is available.
