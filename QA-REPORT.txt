ARANAV PORTFOLIO — V8 CORE QA & OPTIMISATION REPORT
Date: 04 November 2026
Package base: V7 White + Crimson Red

SUMMARY
V8 is a focused quality/performance pass on the existing portfolio. The dark cinematic theme remains the first-visit default; the alternate theme remains white + crimson red.

AUDIT FINDINGS, VERIFICATIONS & FIXES
1. TYPOGRAPHY VERIFICATION
   - Confirmed the active CSS tokens and Google Fonts request consistently use Manrope and Cormorant Garamond.
   - Compact labels use the native system monospace stack by design, avoiding a third remote font download.
   - Kept `display=swap` and safe system fallbacks to avoid blocking initial text paint.
2. THEME FIRST-PAINT FLASH
   - The saved theme was previously applied by the footer script after the page had begun rendering.
   - Theme preference is now read in the head before the stylesheet is painted, with guarded storage access.
3. NARROW MOBILE HEADLINE OVERFLOW
   - The italic hero headline could extend beyond the viewport at 320px.
   - It now wraps naturally at widths up to 360px. Browser measurements show both body and document scroll width match the viewport at tested widths.
4. TABLET HERO COLLISION RISK
   - At 768px the long hero headline approached/overlapped the portrait frame.
   - Tuned the heading scale from 761px to 820px, leaving a clear measured gap between headline and image.
5. WHITE-THEME CONTRAST
   - Improved secondary text contrast and set the white/red primary CTA to a white-on-crimson treatment; dark theme styling remains intact.
6. SKILL-DOOR MOTION TIMING
   - The detail panel was appearing before the 1.05s hinge animation had completed.
   - Synchronised the panel reveal with the door transition; reduced-motion mode skips the hinge movement.
7. NO-JAVASCRIPT FALLBACK
   - Added a safeguard so the preloader does not cover content when JavaScript is unavailable.
