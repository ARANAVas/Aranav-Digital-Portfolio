# V20.1 Responsive Hero QA Report

## Issue fixed
The inherited V20 desktop styling positioned the “Strategy × Craft” capability card absolutely over the bottom-left corner of the signature logo video. On narrow phones the inherited layout flowed the card below the video, so behavior was inconsistent across breakpoints.

## Correction
The hero visual is now a vertical layout at every screen size. The logo-video frame keeps a 16:9 presentation, the “Strategy × Craft” card follows it in normal document flow, and the “Strategy with intent” marker remains above the video. The existing animated logo assets and all other portfolio sections are preserved.

## Responsive verification
- **28 viewport widths tested:** 320, 340, 360, 375, 390, 393, 414, 430, 460, 540, 620, 700, 760, 768, 800, 820, 860, 900, 960, 1024, 1100, 1200, 1280, 1366, 1440, 1600, 1920 and 2560 px.
- **No overlap:** the measured video/card intersection area was zero at every tested width.
- **Minimum gap:** 12 px between the video frame and capability card.
- **No horizontal overflow:** document width matched the viewport at every tested width.
- No console errors or uncaught JavaScript errors in the embedded Chromium smoke test.

## Preserved interactions
All four skill doors opened and closed, the dark/light theme toggle worked, the contact dialog opened and validated required fields, the mobile menu opened, case-study disclosures worked, role headlines rotated, and video loading remained deferred under reduced-motion testing.

## Limits
The test used an embedded Chromium document because local HTTP navigation was blocked in this execution environment. Google Fonts and live-hosted video playback were not independently tested. Physical Android/iOS checks, live-host security-header checks and Lighthouse/Core Web Vitals remain outstanding. This package has not been published.
