ARANAV SHARMA — PORTFOLIO V14
Quiet Luxury / Recruiter Edition

V14 is an additive visual and contact update for the existing Aranav Digital Portfolio.
It keeps the original four-door skill experience, door-to-portal transition, detailed skills, projects, work history, resume asset, contact modal and dark/light theme system.

PRIMARY CHANGES
- New contact address: aranavprime@gmail.com.
- Contact mail links, modal links, email-copy action and script fallback use the new address.
- New visits default to the dark theme; a previously saved light/dark preference is respected.
- Warm charcoal, aged-brass, paper and restrained oxblood palette.
- Editorial serif/sans typography, more intentional spacing and calmer micro-labels.
- Fine, low-opacity material grain; no neon cursor trails, excessive glow, glassmorphism or large gradient decorations.
- Updated hero and profile text to focus on brand strategy, craft and execution.
- Original animated portrait identity retained, using the small WebP marks in header/footer and optimized hero film where supported.
- Responsive refinements for phones, tablets, laptops and large displays.
- A restrained reading-progress hairline, accessible focus treatment and reduced-motion fallback.

FILES
- apply-v14.html: offline helper. Select the original index.html and script.js together. It downloads index-v14.html and script-v14.js separately.
- cinematic-v12.css/js: identity and hero composition layers from V13.
- cinematic-v13.css/js: responsive and lazy hero-media layers from V13.
- cinematic-v14.css/js: V14 visual and interaction refinements.
- assets/photos/*: optimized portrait mark and WebM/MP4 hero video variants.

IMPORTANT
This package does not include a complete copy of the original repository. The offline helper updates the exact original GitHub files selected by the user. Do not select previously generated V13/V14 files.
